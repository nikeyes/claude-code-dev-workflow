# ENG-1234: Add bulk import endpoint to inventory service

## Description

We need to add a bulk import feature to the inventory service that allows uploading a CSV file of products and adding them to the inventory in a single operation. This is needed for the warehouse team's quarterly restocking process.

## Acceptance Criteria

1. New `bulk_import(csv_data: str) -> dict` method on `InventoryService` that parses CSV and creates/updates products
2. Import should return a summary: `{"created": N, "updated": M, "errors": [...]}`
3. If a SKU already exists, update its quantity (add to existing) and price (replace)
4. Invalid rows (missing required fields, negative quantity, non-numeric price) should be collected in the errors list, not abort the entire import

## CSV Format

```
sku,name,quantity,price
SKU001,Widget,100,9.99
SKU002,Gadget,50,19.99
```

## Priority

Medium — needed before Q3 restocking (July 1)

## Notes

- The warehouse team currently does manual entry, ~200 products per restock
- CSV files come from the ERP system, generally clean but occasionally has bad rows
