# Research on HTTP 404

## Executive Summary

HTTP 404 ("Not Found") is a standard HTTP response status code indicating that the server could not find the requested resource. The client's request was valid and reached the server, but the specific URL or file does not exist at that location. It is one of the most common HTTP error codes encountered on the web and is defined in RFC 7231.

## Findings

**HTTP 404 Not Found** means the server understood the request but cannot locate the resource at the given URL. This can happen because:

- The URL was typed incorrectly
- The page was deleted or moved without a redirect
- The link pointing to the resource is outdated (a "broken link")

It differs from 403 Forbidden (resource exists but access is denied) and 410 Gone (resource existed but has been permanently removed).

## Conclusions

- HTTP 404 = server reachable, resource not found at the requested URL
- The request itself was valid; the problem is the resource's absence
- Common causes: typos, deleted pages, broken links
- Defined in RFC 7231 as part of the 4xx client error class
